## How to Run Locally

To launch the local web server:

```bash
# Using agy-node:
agy-node server.js

# Or using standard node:
node server.js
```

Then open your browser to:
- Website: **`http://localhost:3000`**
- Admin Console: **`http://localhost:3000/admin`** (Passcode: `admin123`)

## Deploying to Vercel

This repository is pre-configured with `vercel.json` and a serverless API function (`api/index.js`):

1. Push this repository to GitHub: `https://github.com/nomanrangrej/Speakerpartpro`.
2. In [Vercel](https://vercel.com/), click **Add New...** > **Project**.
3. Import the **Speakerpartpro** repository.
4. Keep the default settings and click **Deploy**.
5. Your project will be live with instant global edge routing and API functionality!
